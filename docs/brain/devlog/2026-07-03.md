## Decisions

- Student Agent is a controlled learning partner, not a generic chatbot or homework-completion tool.
- Student Agent answers are private by default.
- Teacher-visible sharing requires an explicit student action.
- Student original stuck notes remain the evidence source; Agent summaries are drafts or previews.
- Teacher Agent output remains draft-only until a teacher explicitly approves an action.
- Teacher Agent actions are persisted as workspace records and scoped back to the relevant student alias; dismiss/handled actions are teacher-only.
- Outcome evaluation is a learning-signal comparison layer, not grading, psychological assessment, or a claim that a teacher action caused improvement.

## Problems

- Browser workflow initially failed because the new share-to-teacher route wrote only `student_agent_share_to_teacher`; fixed by also writing a compatible `record_stuck_signal` audit event.
- Browser workflow also expected the raw stuck note to remain unchanged; fixed by storing the original note as evidence while keeping the cleaned summary in the returned draft.
