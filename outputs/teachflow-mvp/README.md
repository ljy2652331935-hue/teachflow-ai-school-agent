# TeachFlow MVP

Stable hackathon demo for the TeachFlow teaching workflow.

## Run

```bash
npm install
npm run dev
```

On Windows PowerShell, if npm scripts are blocked by execution policy, use:

```bash
npm.cmd install
npm.cmd run dev
```

Or run:

```bash
start-demo.bat
```

Then open:

```text
http://localhost:5173
```

## Demo Scope

- Teacher Dashboard
- Misconception Map
- Differentiated Materials
- Teacher Control Panel
- Student Portal
- Mock output from data/mock-output.json
- Approval, publish, rollback, and audit log states
