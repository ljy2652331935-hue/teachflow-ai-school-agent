# Lesson Note: Fourier Transform

Topic: Fourier Transform

Fourier Transform is a mathematical tool that converts a signal from the time domain into the frequency domain.

In the time domain, we see how a signal changes over time.

In the frequency domain, we see what frequencies make up the signal.

A complex signal can be decomposed into many simple sine and cosine waves.

Fourier Transform is used in:
- Music and audio analysis
- Image compression
- MRI scanning
- Signal processing
- Quantum mechanics
- Data analysis
