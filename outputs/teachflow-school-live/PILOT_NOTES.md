# TeachFlow v0.3 Pilot Notes

## Product Definition

TeachFlow v0.3 is a teacher-controlled AI school system MVP for diagnosis, intervention planning, student material delivery, understanding maps, and project-level agent guidance.

It turns anonymised student answers into:

- class understanding summary
- misconception map
- evidence quotes
- likely root causes
- teaching needs
- revised teaching plan
- Level 1, Level 2, and Level 3 differentiated materials
- visual aid prompt
- video storyboard
- micro quiz
- teacher notes
- student-facing handout
- section approval states
- version history
- structured audit log
- Markdown export package
- teacher-only student understanding memory
- micro-quiz follow-up memory update
- controlled Student Portal Lite
- alias-based material assignments
- student reflection submissions
- student micro-quiz submissions
- student stuck signals
- student understanding map nodes
- class understanding map summary
- School Agent Console readiness and morning brief

It is not a student chatbot, automatic grader, or school admin dashboard.

## First School Trial Goal

Let one teacher paste a real set of anonymised student responses and quickly answer:

> What did students truly not understand, and what evidence shows that?

Then let the teacher inspect the generated intervention and answer:

> Would this help me adjust tomorrow's lesson for different student groups?

Finally, let the teacher use the Review & Approval Studio and answer:

> Do I feel in control of what the AI generated before it becomes teaching material?

Then let the teacher open Student Memory and answer:

> Does this help me remember what each anonymised student alias currently needs next?

Finally, let the teacher publish to Student Portal Lite and answer:

> Can a student alias safely receive the right approved material, answer the micro quiz, and submit a reflection without open AI access?

Then let the student alias open My Understanding Map and answer:

> Does this help me see what I understand, what I still need help with, and how to ask for a different explanation?

Finally, let the teacher open School Agent Console and answer:

> Does the system clearly recommend the next safest, most useful step for a school pilot?

## Teacher Interview Questions

1. How do you currently know what students did not understand?
2. How long does it take to review short student answers after a lesson?
3. Would exact student evidence make AI output more trustworthy?
4. What language would make misconception labels feel fair rather than judgmental?
5. Would you use this report to plan the next lesson?
6. Are the Level 1, Level 2, and Level 3 materials useful enough to edit rather than rewrite?
7. Do misconception-ID links make the intervention feel traceable and trustworthy?
8. What would you change before using the exported Markdown with students?
9. Are section-level approvals clearer than one overall approval button?
10. Does version history make rollback feel safe enough for school use?
11. Is the audit log understandable to a non-technical teacher?
12. Are Student Memory weak points phrased as temporary learning states rather than judgments?
13. Would micro-quiz follow-up updates help plan the next lesson?
14. Does Student Portal Lite feel controlled enough for a school trial?
15. Is alias selection understandable without exposing real student identities?
16. Would the reflection and micro quiz submissions provide useful follow-up evidence?
17. Does the Understanding Map feel supportive rather than judgmental?
18. Are "I am stuck because..." options understandable to students?
19. Would the School Agent Console help a teacher know what to do next?
20. Are the agent guardrails strong enough for a pilot conversation with school staff?

## Next Build Step
